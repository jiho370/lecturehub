# /lecture-note — 강의자료를 뼈대로, 전사로 채운 강의 정리본

앱(파이썬)은 **모으기와 연결**만 한다. 읽고 쓰는 일은 이 세션이 한다.

앱이 이 세션을 열 때 환경 변수 두 개를 넣어 준다. 비어 있으면 멈추고 사용자에게 알린다.

```
LECTUREHUB_PY    앱의 파이썬 (예: ...\python.exe)
LECTUREHUB_ROOT  학기 폴더 (사용자가 첫 실행 설정에서 고른 폴더)
"%LECTUREHUB_PY%" -m lecturehub lecture note-pack <회차 id> --root "%LECTUREHUB_ROOT%"      → JSON 한 줄
"%LECTUREHUB_PY%" -m lecturehub lecture attach-note <회차 id> "<파일>" --root "%LECTUREHUB_ROOT%"
"%LECTUREHUB_PY%" -m lecturehub quiz cues "<발언 파일>" --root "%LECTUREHUB_ROOT%"            (7단계)
```
`note-pack`이 "No such command"로 실패하면 멈추고 그렇게 말한다(앱 버전이 맞지 않는 것이다).
앱이 `LECTUREHUB_NOTE_PACK`(앱이 미리 만든 묶음 JSON 파일)을 넣어 주면 `note-pack`을 실행하지 말고 그 파일을 읽는다(`utf-8`).
Codex에서는 학기 폴더 중 `notes_folder`(정리본)와 `cues_file`의 폴더만 쓸 수 있다. `attach-note`·`quiz cues`는 데이터베이스를 쓰므로
실행할 때 승인을 묻는다 — 사용자에게 무슨 명령인지 한 줄로 말하고 승인을 받는다. 승인 없이 우회하지 않는다.
**녹음 중에는 시작하지 않는다**(PDF 렌더가 무겁다): 묶음의 `recording_now`가 true면 멈추고 녹음이 끝난 뒤에 한다. 쓰기 직전에 한 번 더 본다:
`%LECTUREHUB_ROOT%\_lecturehub\recordings\*\` 중 `.recording.lock`은 있고 `stop.json`은 없는 폴더가 있으면 녹음 중이다.

## 지킬 것 (먼저)
1. **학기 폴더는 읽기 전용**이다. 쓰는 것은 묶음의 `target`(과목 폴더의 `정리본\` 안 새 HTML)과, 7단계의 `cues_file`(`_lecturehub` 안) 둘뿐. 전사·녹음·슬라이드·기존 노트는 고치지 않는다.
   `attached_notes`가 있으면 그 파일이 이 회차의 노트다 — 새로 만들지 말고 **그 파일을 제자리에서 고친다**(고치기 전 사본을 임시 폴더에).
2. **전사에 없는 말을 지어내지 않는다.** 슬라이드에만 있고 말하지 않은 내용은 "슬라이드에만 있음"으로 구분한다.
3. 노트는 **공부할 사람이 읽는 글**이다. 누구 전사인지, 언제 고쳤는지, 무엇을 정정했는지 같은 작업 이력을 본문에 쓰지 않는다
   (보충 절·정정 표 대신 본문을 고친다). 확정 못 한 값만 `p.note`에 "A 또는 B로 들림"으로 짧게.
4. 데이터베이스를 직접 건드리지 않는다. 연결은 `attach-note`로만.
5. 다른 사람의 유료 강의·영상은 길게 옮겨 적지 않고 자기 말로 정리한다. 출석 호명의 이름은 옮기지 않는다.
6. 압축 파일 안의 프로그램은 실행하지 않는다(문서만 읽는다).
7. 이 노트는 **개인 학습용**이다. 슬라이드와 시험 자료에는 저작권이 있으므로 노트 끝에 "개인 학습용 · 공유 금지" 한 줄을 넣는다.

## 절차
1. `LECTUREHUB_NOTE_PACK` 파일(없으면 `note-pack`)로 묶음을 받는다. `ready`가 false면(전사 없음) 멈추고 그렇게 말한다.
2. `lecture-notes-html` 스킬이 있으면 불러 그 절차(녹취 충실성, 이미지 추출, QA)를 따른다.
3. **전사를 모두 읽고 나란히 대조**한다(`transcripts`: 엔진마다 한 파일, `in_use`가 사용본, `qa`에 경고).
   - PC 소리 녹음(`recordings[].mode`)은 소리가 날 때만 저장된다. 전사 시각은 녹음 안의 시각이라고 노트에 한 번 밝힌다.
   - 수업이 끝난 뒤의 무음·반복 환각·사담은 넣지 않고 "몇 분 이후는 수업 뒤 녹음" 한 줄만.
   - 엔진마다 시각이 어긋나면 **사용본(`in_use`)의 시각**을 쓰고, 사용본에 없는 구간만 다른 전사의 시각을 쓴다.
   - 중요한 말에서 녹음이 끊겼거나 모든 전사가 뭉갰으면 "추정"으로 표시하고 보고에 적는다. 그 구간만 잘라 다른 엔진으로 다시 전사하는 것은 사용자가 원할 때만 한다.
   - **한 엔진만 같은 말을 되풀이하는 구간**은 그 엔진을 빼고 다른 전사로 쓴다. 한 전사에만 있는 말은 그렇다고 적는다.
4. **강의자료를 찾는다**: `materials_linked`(앱이 이 회차에 연결한 자료와 쪽)를 먼저 보고, 없거나 맞지 않으면
   `materials_in_course_folder`에서 전사 내용으로 장·쪽을 직접 찾는다. PDF는 pypdfium2로 텍스트를 뽑고 다룬 쪽을 이미지로 렌더해 넣는다(base64 내장).
   - **그날 슬라이드가 과목 폴더에 없으면** 사용자가 해당 파일을 앱에 추가하도록 알린다. 다운로드·메신저 폴더를 임의로 검색하지 않는다. 추가 자료가 필요하면
     **멈추고 사용자에게 알린다**(파일 정리는 앱의 eTL 자료 화면에서 사용자가 누른다). eTL 자료 목록 `%LECTUREHUB_ROOT%\_lecturehub\etl\files.json`(있으면)에서
     그 날짜 무렵 올라온 파일도 찾아 이름을 알린다. 그래도 없으면 녹음만으로 쓰고, 노트 머리말에 "이날 슬라이드 없이 녹음으로 정리"라고 밝힌다.
     같은 과목의 다른 자료를 대신 쓰면 "참고 자료"라고 구분한다.
5. **쓴다** — 슬라이드를 뼈대로, 강의에서 말한 순서(시간순)대로.
   - 형식은 `style_from`(이 과목의 가장 최근 회차 노트 — 시험 대비·기출 분석 페이지는 제외)의 `<style>`·구조·클래스를 그대로 따른다. 없으면 깔끔한 단일 HTML(목차, 절 제목, 표)로 만든다. 그림이 든 큰 파일은 통째로 읽지 말고 스타일과 본문 일부만 본다.
   - 파일 이름은 `target`(그 과목 노트 이름 관례에 날짜만 바꾼 것)을 쓰되, 같은 이름이 있으면 덮어쓰지 않는다.
   - 절 제목에 대략의 시각과 슬라이드 쪽. 수식·표는 슬라이드와 맞춰 정확히, 예제는 풀이 단계를 따라 쓰고 숫자는 검산한다.
   - 용어·숫자가 전사끼리 갈리면 슬라이드로 판정하고, 안 되면 규칙 3대로.
   - **시험·퀴즈·과제·발표·휴강·일정·"중요하다"** 언급은 따로 모아 맨 위 상자에(말한 시각 포함).
6. **확인한다**: 태그 짝, 목차 링크와 절 id, 그림 수와 데이터 길이. 화면은 헤드리스 브라우저(Edge 또는 Chrome)로 찍는다:
   `msedge.exe --headless --disable-gpu --window-size=1000,2400 --screenshot=<png> "file:///<노트 경로>"`
   브라우저를 찾지 못하면 이 단계는 건너뛰고 보고에 "화면 확인 못 함"이라고 적는다.
7. `attach-note`로 회차에 연결한다(이미 연결된 파일을 고쳤으면 다시 실행해 해시를 갱신).
   시험·퀴즈·"중요하다"·범위 언급을 모았으면 묶음의 `cues_file`에 아래 형식으로도 써 두고 `quiz cues`로 넣는다 — 앱의 [시험] 화면
   "수업 중 발언"에 들어간다. **전사에 있는 말 그대로**(quote) 적는다: 앱이 그 회차의 **모든 전사**에서 그 시각 ±4분 안에 그 말(글자쌍 60% 이상)을
   찾지 못하면 넣지 않는다. 결과의 `skipped`에 빠진 번호와 이유가 나온다. 전사 파일은 BOM으로 시작할 수 있으니 직접 대조할 때는 `utf-8-sig`로 읽는다.
   ```json
   {"version": 1, "course": "<묶음의 course>", "cues": [
     {"date": "<묶음의 date>", "at": "42:35", "kind": "emphasis", "quote": "<전사에 있는 말 그대로>", "note": "<한 줄 메모>"}]}
   ```
   kind: `exam_mention`(시험·퀴즈에 나온다) · `exam_exclusion`(**시험에** 안 낸다·범위에서 뺀다 — 앱이 "안 낸다고 함"으로 보인다) ·
   `emphasis`(중요·꼭 알아야, 그리고 공부 방법 안내) · `scope_notice`(범위·일정·다음 시간 진도).
   `at`은 "42:35", "1:04:51", "01:04:51" 모두 된다.
   언급이 없으면 파일을 만들지 않는다.
8. **보고**: 파일 경로와 크기, 다룬 자료(파일·쪽), 일정·시험 언급 목록, 확정 못 한 곳, 확인한 것과 확인 못 한 것.
   앱 화면은 회차를 다시 열면 노트가 보인다.
