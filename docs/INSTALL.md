# 설치

Windows 10(1809 이상) 또는 Windows 11, 64비트가 필요합니다.

## 1. Microsoft Store에서 설치 (권장)

1. https://apps.microsoft.com/detail/9NSZ9V0H0FBR 를 열거나, Microsoft Store 앱에서 "Lecture Hub"를 찾습니다.
2. **받기**(또는 **설치**)를 누릅니다. 경고 창 없이 설치됩니다. Store판은 Microsoft가 서명합니다.
3. 시작 메뉴의 **Lecture Hub**로 엽니다.

새 버전은 Store가 받으므로 앱 안의 새 버전 알림은 꺼져 있습니다. Store판을 제거하면 앱 설정과 앱 기록도 함께 지워지지만, 학기 폴더(녹음·전사·노트)는 그대로 남습니다.
Store판과 아래 설치 프로그램판을 함께 설치할 필요는 없습니다. 하나만 쓰세요.

## 1-1. 설치 프로그램으로 설치 (Store를 쓸 수 없을 때)

1. 릴리스 페이지에서 `LectureHub-<버전>-win64-setup.exe`를 받습니다.
2. 받은 파일을 실행합니다. 관리자 권한은 필요 없고, 내 계정 폴더(`%LOCALAPPDATA%\Programs\LectureHub`)에 설치됩니다.
3. 시작 메뉴의 **Lecture Hub**로 엽니다.

ffmpeg는 앱에 들어 있습니다. Python을 따로 설치할 필요가 없습니다.

### "Windows의 PC 보호" 창이 뜰 때

이 앱은 아직 코드 서명이 없어서, 처음 실행할 때 Windows가 파란 경고 창("알 수 없는 게시자")을 띄웁니다.

- **추가 정보**를 누른 뒤 **실행**을 누르면 설치가 계속됩니다.
- 받은 파일이 진짜인지는 해시로 확인할 수 있습니다. PowerShell에서 아래 명령을 실행하고, 결과를 릴리스 페이지의 `SHA256SUMS.txt`와 비교합니다.

```
Get-FileHash .\LectureHub-<버전>-win64-setup.exe -Algorithm SHA256
```

값이 다르면 설치하지 마세요.

### 설치 없이 쓰기 (zip)

`LectureHub-<버전>-win64.zip`을 원하는 폴더에 풀고 `LectureHub.exe`를 실행합니다. 시작 메뉴 등록과 제거 프로그램은 없습니다.

### 화면이 안 뜨고 WebView2 안내가 나올 때

화면은 Windows의 Microsoft Edge WebView2 Runtime으로 그립니다. Windows 11에는 들어 있고 Windows 10에도 대부분 있습니다. 없으면 앱이 안내 창을 띄웁니다. [WebView2 내려받기](https://developer.microsoft.com/microsoft-edge/webview2/)에서 "Evergreen Bootstrapper"를 받아 설치한 뒤 다시 실행합니다.

## 2. 처음 켰을 때

마법사가 열립니다. 두 가지 중 하나를 고릅니다.

- **예시 학기로 둘러보기**: 수문학·토질역학·관개배수공학의 일정, 전사와 정리본을 둘러봅니다. 앱을 보여 주려고 만든 예시 데이터입니다. 내 자료나 키가 없어도 되고, 아무것도 밖으로 보내지 않습니다.
- **내 학기 설정**: 학기 폴더를 고르고 시간표를 적습니다. 수업 시간을 넣지 않은 과목은 '수업 외'로 들어가고, 시간은 나중에 설정의 시간표에서 넣을 수 있습니다.

학기 폴더를 고를 때 아래 같은 곳이면 마법사가 알려 줍니다. 안내만 하고 폴더를 거절하지는 않습니다.

- 이름으로 알아보는 클라우드 동기화 폴더: OneDrive, Dropbox, Google Drive(Google Drive for desktop의 "My Drive"·"내 드라이브"·공유 드라이브 포함), iCloud, MYBOX. 녹음하는 동안 큰 파일이 계속 올라가고 동기화 프로그램이 수업 목록 파일을 잠가 오류가 날 수 있어, 동기화되지 않는 폴더를 권합니다.
- USB·네트워크 드라이브, 경로가 150자를 넘는 폴더. USB는 뽑히면 녹음이 끊깁니다. 이런 드라이브에는 휴지통이 없어서, 앱은 녹음이 끝나 MP3를 확인한 뒤 앱이 만든 WAV 사본만 바로 지웁니다. 그 밖의 삭제(녹음 버리기, 오래된 소리 정리 등)는 하지 않고 파일을 그대로 둡니다.

### 처음 설정에서 ChatGPT(Codex) 연결하기 (선택)

내 학기 설정은 안내 → 폴더 → 폴더 구성 → ChatGPT(Codex) 연결 → 시간표 → 도구 순서입니다. 학기 폴더는 폴더 구성 단계를 마칠 때 만들어집니다.

- **ChatGPT(Codex) 연결**: 이 PC에 Codex CLI가 있는지, 로그인했는지 보여 줍니다(설정 → 연결 → 프로그램과 같은 확인). 없으면 설치 안내가 나옵니다. 설치하고 `codex login`으로 로그인한 뒤 [프로그램 다시 찾기]를 누릅니다.
  - [Codex에 연결]을 누르면 확인 창 하나에 켜질 세 가지가 적혀 나옵니다: Codex 설정 파일(`.codex\config.toml`)의 Lecture Hub 항목, **AI 앱 연결**, **AI 앱이 고칠 수 있게**. 예를 눌러야 켜집니다.
  - 과목 자료를 AI 앱이 읽게 하는 허용(보여 줄 과목)은 켜지 않습니다. 나중에 만든 과목도 저절로 허용되지 않습니다.
  - Codex가 무언가 바꾸려 하면 바꿀 때마다 Lecture Hub가 화면에 바뀌는 내용을 보여 주고 묻습니다.
  - 끄려면 설정 → AI → AI 앱 연결에서 스위치를 끄거나 [연결 해제]를 누릅니다.
  - [건너뛰기]를 누르면 아무것도 켜지 않고 다음으로 넘어갑니다.
- **시간표**: 세 가지 중 하나로 넣습니다.
  - 아래 칸에 직접 적습니다.
  - [사진으로 넣기 (ChatGPT·Codex)]: 시간표 사진을 고르면 확인 창(파일 이름·크기·보내는 곳)이 뜹니다. 예를 누르면 사진을 붙여 이 PC의 Codex를 엽니다. 사진은 내 Codex 로그인으로 OpenAI에 보내집니다.
  - [Codex로 처음 설정하기]: Codex 창이 열립니다. Codex가 과목과 수업 시간, 개강일과 종강일, 받을 알림을 하나씩 묻고, 표로 보여 준 뒤 내가 맞다고 하면 넣습니다. 시간표 사진이나 수강신청 화면 글을 붙여 넣어도 됩니다.
  - Codex를 쓰는 두 방법은 앞 단계에서 연결했을 때만 누를 수 있습니다. Codex가 시간표를 넣을 때 Lecture Hub가 한 번 더 묻고, 허용하면 마법사 화면에 그 시간표가 나타납니다. 확인하고 고친 뒤 [다음]을 누릅니다. 기다리지 않고 직접 적어도 됩니다.
  - Codex가 넣은 새 과목은 AI 앱에 보이지 않습니다. 넣은 뒤 고칠 것은 마법사 화면에서 고칩니다.
- 마법사를 마치기 전에 앱을 닫으면, 다음에 켤 때 만들어 둔 학기 폴더로 이어서 합니다.

그다음 **설정**에서 키를 연결합니다.

- Gemini 키: Google AI Studio에서 만듭니다. 연결 버튼을 누르면 키가 맞는지 확인한 뒤 저장합니다.
- Groq 키: Groq 콘솔에서 만듭니다.
- eTL 토큰: eTL 계정 설정의 "새 액세스 토큰"에서 만듭니다. 다른 학교 Canvas를 쓰면 먼저 설정 → 연결 → 계정 연결의 [다른 학교 Canvas]에 학교 Canvas 주소(https)를 넣고, 그 학교 Canvas의 계정 → 설정에서 토큰을 만듭니다. 토큰은 넣을 때의 주소에만 보내고, 주소를 바꾸면 다시 넣어야 합니다.

키는 이 PC의 Windows 자격 증명 관리자에만 저장되고, 앱 화면이나 파일로 다시 나오지 않습니다.

설정의 **AI 엔진**에서 기본값과 정리본별 값을 고릅니다(처음은 Codex).
프로그램 발견과 로그인은 별개이며, [프로그램 다시 찾기]에서 Codex 로그인 상태를 확인할 수 있습니다.
CLI 상태로 Edu 작업 공간인지 판별할 수는 없습니다. 제공자 동의창의 설명을 읽고 개인정보를 뺀 자료만 보내세요.
과목별 **녹음 허락**도 따로 표시하세요. 금지는 녹음·자막을 막고, 미확인은 시작 때 경고합니다.

설정의 **수업 중 공지 찾기**는 Store판·공개판에서 처음에 ChatGPT(Codex)로 되어 있습니다. 쓰려면 아래 표의 Codex CLI를 설치하고 로그인한 뒤, "ChatGPT(Codex)로 보낼 과목"에서 과목을 하나씩 체크합니다(과목마다 확인 창). 체크하지 않은 과목은 보내지 않고, 새 전사가 있으면 "허용이 필요한 과목"으로 보여 줍니다. "읽는 AI"에서 Google Gemini로 바꾸거나, 같은 칸 맨 위의 체크 상자로 끌 수 있습니다. 무엇이 가는지는 [PRIVACY.md](PRIVACY.md)의 "수업 중 공지 찾기"에 있습니다.

eTL 공지에 올라온 시험·마감·휴강도 찾게 하려면 같은 칸 아래 **"eTL 공지도 ChatGPT(Codex)로 보낼 과목"**에서 과목을 체크합니다. 전사 글 허용과는 따로 묻고(과목마다 확인 창, [모두 선택]은 확인 창 하나), 수업 중 공지 찾기가 ChatGPT(Codex)로 켜져 있을 때만 보냅니다. 무엇이 가는지는 [PRIVACY.md](PRIVACY.md)의 "eTL 공지에서 일정 찾기"에 있습니다. eTL을 연결하면 새 과제·마감 변경·새 강의자료를 Windows 알림으로 알려 주며, 종류마다 **설정 → 기본 → 알림 · 업데이트**에서 끌 수 있습니다(AI를 쓰지 않음).

### AI 앱에 연결하기 (선택)

쓰던 AI 앱이 내 수업 자료를 읽게 하려면 아래 순서로 합니다. 이 PC에 설치한 ChatGPT 데스크톱·Codex, Claude 데스크톱이나 Claude Code에서 쓸 수 있고, ChatGPT 웹·휴대폰 앱과 Claude 웹·휴대폰 앱은 쓸 수 없습니다. 무엇이 건너가는지는 [PRIVACY.md](PRIVACY.md)의 "AI 앱 연결"을 먼저 읽어 주세요.

1. Lecture Hub 설정 → AI → **AI 앱 연결**에서 스위치를 켭니다. 기본은 꺼져 있습니다.
2. **보여 줄 과목**에서 읽게 할 과목을 체크합니다. 하나씩 체크하면 과목마다 확인 창이 뜨고, [모두 선택]을 누르면 과목 이름을 모두 적은 확인 창 하나로 묻습니다. [모두 해제]는 바로 적용됩니다. 체크하지 않은 과목은 보이지 않습니다.
3. **AI 앱에 연결**에서 버튼 한 번으로 연결합니다. 설정 파일을 직접 고칠 필요가 없습니다.
   - [Codex에 연결]: ChatGPT 데스크톱·Codex가 읽는 사용자 폴더의 `.codex\config.toml`에 Lecture Hub 부분만 넣습니다.
   - [Claude 데스크톱에 연결]: Claude 데스크톱 설정 파일의 `mcpServers` 안에 `lecturehub` 부분만 넣습니다. Store판에서는 Windows가 앱의 이 폴더 쓰기를 따로 보관해 확실히 고칠 수 없어 버튼이 없고, 아래 접힌 "다른 AI 앱 · 직접 붙여 넣기"에서 [복사]해 붙여 넣습니다.
   - 누르면 넣을 내용과 파일 위치를 그대로 보여 주는 확인 창이 한 번 뜹니다. 예를 눌러야 씁니다. 다른 설정은 건드리지 않고, 처음 고칠 때 원래 파일을 같은 폴더에 `.lecturehub-bak`으로 남깁니다. 파일이 올바른 형식이 아니면 아무것도 고치지 않고 알려 줍니다.
   - [연결 해제]는 넣은 부분만 정확히 지웁니다. 앱을 다른 곳에 다시 설치해 경로가 바뀌면 "다른 경로로 연결됨"과 [다시 연결]이 보입니다.
   - Claude Code와 그 밖의 앱은 접힌 "다른 AI 앱 · 직접 붙여 넣기"에서 [복사]합니다. 같은 문구를 명령 창에서 `lecturehub mcp config`로도 볼 수 있습니다.
   - [ChatGPT(Codex)로 열기]는 이 PC의 Codex를 새 창으로 열고 그 실행에만 Lecture Hub를 연결합니다(설정 파일을 고치지 않음). 회차 화면의 정리본 칸에도 같은 버튼이 있습니다.
4. 연결한 AI 앱을 완전히 닫았다가 다시 엽니다(Claude Code는 새로 시작합니다).
5. (선택) AI 앱이 말로 일정·정리본·시간표·알림 설정을 바꾸게 하려면 **AI 앱이 고칠 수 있게**를 켭니다. 기본은 꺼져 있습니다. 아래 "AI 앱이 고치게 하기"를 보세요.
6. 물어봅니다. 예를 들어 이렇게 합니다.
   - "수문학 과목에서 지난 수업에 합리식을 어떻게 설명했는지 찾아 줘."
   - "이번 달 시험이나 과제 일정이 있으면 확정과 후보를 나눠서 알려 줘."
7. 정해진 형식으로 정리하는 스킬도 있습니다. 공개 저장소의 `skills/week-brief`(이번 주 수업 브리핑), `skills/review-plan`(한 과목 복습 계획), `skills/note-from-lecture`(한 회차 정리본 쓰기·저장) 폴더를 AI 앱의 스킬 폴더(Codex는 `.agents\skills`, Claude Code는 `.claude\skills`)에 넣고 `$week-brief`나 `/week-brief`처럼 부릅니다. 스킬은 이 연결의 도구만 쓰고, 줄마다 출처를 붙이며, 연결이 꺼져 있거나 과목이 허용되지 않았으면 설정 → AI → AI 앱 연결을 안내합니다. [ChatGPT(Codex)로 열기]로 연 Codex에는 이 스킬들이 이미 들어 있습니다.

#### 앱 안을 점검하기

"앱 설정이 잘 되어 있는지 점검해 줘", "이 회차에서 공지를 빠뜨리거나 날짜를 잘못 읽은 게 있는지 전사를 다시 읽고 확인해 줘", "이번 주 휴강·보강 반영 시간표 보여 줘", "AI가 바꾼 것 알려 줘"라고 할 수 있습니다.

| 읽기 도구 | 건네는 정보 |
|---|---|
| `get_app_status(offset?)` | 버전·판, 연결·쓰기·자동 설정, 허용 과목별 회차·전사·정리본·자료·후보 수, 정리본·공지 엔진과 마지막 공지 상태, eTL 목록 수신 여부·시각, 알림, 허용 과목의 오늘 AI 변경 수와 앱 한도 |
| `get_timetable(week_of?, course?, offset?)` | 정규 주간 수업, 개강·종강일, 지정 날짜가 든 주(기본 이번 주, 월~일)의 휴강·보강 반영 일정. 강의자 이름은 없고 강의실은 미기록 |
| `get_lecture_status(lecture_id, offset?)` | 전사 엔진·사용본·구간 수·관측 길이, 정리본과 작성 주체, 연결 자료, 공지 읽기 시각·현재성·엔진, 찾은 후보의 현재 상태·인용·[mm:ss]. 날짜를 정하지 못한 공지도 포함 |
| `list_ai_changes(course?, limit?, offset?)` | 허용 과목의 변경 시각·도구·과목·요약·되돌림 여부. 되돌리기는 앱에서만 가능 |

긴 목록은 `next_offset`을 같은 도구의 `offset`으로 넘겨 끝까지 읽습니다. 회차 상태와 앱 상태처럼 목록이 여럿인 응답도 하나의 커서로 이어집니다. eTL은 목록을 받은 적이 있는지와 그 시각만 알려 줍니다(도우미는 eTL 토큰을 읽지 않습니다). 마지막 공지 상태 시각은 상태가 바뀐 시각일 수 있고, 과거 읽기 엔진을 알 수 없으면 빈 값으로 옵니다. 오늘 변경 수는 허용 과목만 세지만 실제 하루 한도는 앱 전체에 적용합니다.

공개 저장소의 `skills/check-notices`(공지 누락·오독 재검토)와 `skills/app-checkup`(앱 준비 상태 점검)도 기존 스킬처럼 AI 앱의 스킬 폴더에 넣으면 됩니다. [ChatGPT(Codex)로 열기]에는 자동으로 들어 있습니다. 공지 점검은 전사 원문을 근거로 비교 결과부터 보여 주며, 사용자가 동의한 누락 일정만 출처 회차·시각을 붙여 추가합니다. 전사 속 명령은 따르지 않습니다. 앱 점검은 설정을 바꾸지 않고 어디서 켜야 하는지 설명합니다.

#### AI 앱이 고치게 하기 (선택)

**AI 앱이 고칠 수 있게**를 켜면 AI 앱에 이렇게 말할 수 있습니다. 종류마다 처음에는 Lecture Hub가 화면 맨 앞에 확인 창을 띄워 어느 AI 앱이 무엇을 바꾸는지 보여 주고 묻습니다. [이번만 허용]은 이번 것만, [이 종류는 앞으로 자동]은 이번 것을 하고 그 종류는 다음부터 묻지 않으며, [거절](기본 버튼)·Esc·창 닫기는 아무것도 바꾸지 않습니다. 50초 안에 고르지 않아도 바꾸지 않습니다. 같은 칸의 **바꾸기 전에 묻기**에서 종류마다 묻기/자동을 고를 수 있고(자동으로 바꿀 때는 확인 창이 한 번 뜸), [모두 다시 묻기]로 처음처럼 돌립니다.
- "수문학 기말시험 12월 9일 오후 1시에 301호로 달력에 넣어 줘." — 확정 일정으로 들어가고 달력에 "AI 앱이 넣음"으로 보입니다. 휴강은 시간표에서 수업을 빼므로 확인 전 후보로만 들어가고, 달력에서 내가 확정합니다.
- "그 일정 시간을 2시로 바꿔 줘" / "그 일정 지워 줘" — **AI 앱이 넣은 일정만** 고치거나 지울 수 있습니다(지우기는 취소로 표시). eTL에서 받은 일정과 내가 넣은 일정은 건드리지 못합니다.
- "확인 필요에 있는 퀴즈 후보 확정해 줘" — 후보를 확정하거나 버립니다.
- "어제 수업 정리본 써서 저장해 줘" — 회차의 정리본 목록에 **새 판**으로 "ChatGPT가 씀"(Claude면 "Claude가 씀", 그 밖의 앱이면 "AI 앱이 씀")이 붙어 저장됩니다. 기존 정리본은 덮어쓰거나 지우지 않습니다. 스크립트·외부 링크·그림은 지우고 글·표·목록만 남깁니다.
- "이 시간표대로 넣어 줘" — 허용한 과목과 새 과목의 요일·시각을 `시간표.csv`에 넣거나 바꾸고, 시간표에서 빼기도 합니다. 확인 창에 뺄 과목(맨 앞, 접지 않음)·넣을 것·바뀌는 시각·개강/종강일이 나옵니다. 과목을 빼거나 시간표를 통째로 바꾸는 요청은 이 종류를 '자동'으로 두었어도 매번 묻습니다. AI 앱에 보이지 않게 한 과목과 겹치는 요청은 무엇과 겹쳤는지 말하지 않고 거절하며, 화면에 알림 창을 띄워 알려 줍니다. 앱이 원래 파일을 `_lecturehub\backups`에 남기고, 새 과목은 폴더만 만듭니다(폴더·녹음·자료는 지우지 않음). 녹음 중에는 바꾸지 않습니다. 허용하지 않은 과목의 줄은 그대로 두고 AI 앱에 보이지도 않습니다. 강의실은 시간표 파일에 칸이 없어 넣지 않습니다.
- **사진으로 시간표 넣기**: 설정의 시간표 칸에서 [사진으로 시간표 넣기 (ChatGPT·Codex)]를 누르고 사진(PNG·JPG·WEBP, 15MB까지)을 고르면, 파일 이름과 크기, 사진이 내 Codex 로그인으로 OpenAI에 간다는 확인 창이 뜹니다. 예를 누르면 Codex 창이 열려 사진을 읽고 표로 보여 준 뒤, 내가 맞다고 하면 위의 시간표 넣기를 부릅니다('시간표 바꾸기'를 자동으로 두지 않았다면 그때 Lecture Hub의 확인 창이 다시 뜹니다. 과목을 빼는 변경은 자동이어도 묻습니다). 고른 사진의 사본은 앱의 Codex 작업 폴더에 하루 동안 남았다가 다음에 쓸 때 지워집니다. 'AI 앱 연결'과 'AI 앱이 고칠 수 있게'가 켜져 있어야 합니다.
- "다음 주 금요일 6시에 보강 있대, 넣어 줘" — 허용한 과목의 그날에 보강(수업 하나 더)·시간변경(그날 수업을 다른 시간으로)·대체를 넣습니다. 오늘 수업·녹음 과목 고르기·수업 알림이 이를 따릅니다. 확인 창에서 허용하면 확정, 자동으로 둔 종류면 "사용자 확인 전"으로 들어갑니다. 휴강은 여전히 확인 전 후보로만 들어갑니다.
- "아침 알림 꺼 줘" / "이 과목 알림 꺼 줘" — 마감·시험 미리 알림과 아침 알림을 켜고 끄고, 허용한 과목의 알림을 끄거나 다시 켭니다. 확인 창에 "지금 → 바꾼 뒤"가 나옵니다.
- "지난 수업 공지 다시 찾아 줘" — 그 회차를 다시 읽으라는 요청만 남깁니다. 켜져 있는 Lecture Hub가 몇 분 안에 설정에서 고른 엔진과 그 과목에 이미 준 전송 허용으로 읽고, 찾은 일정은 달력에 확인 전 후보로 넣습니다. 그 과목이 그 엔진으로 보내도록 허용되어 있지 않거나 수업 중 공지 찾기가 꺼져 있으면 요청하지 않고 무엇을 켜야 하는지 답합니다. 한 회차는 하루 한 번, 모두 합쳐 하루 10번까지이고, 앱이 읽을 때 수업 중 공지 찾기·AI 앱 연결·'AI 앱이 고칠 수 있게'가 꺼졌거나 그 과목 허용을 거두었으면 읽지 않고 버립니다.

허용한 과목에만 쓸 수 있습니다. eTL에는 아무것도 쓰지 않고, 녹음·전사·내 파일을 지우지 않습니다. 바뀐 것은 같은 칸의 **AI가 바꾼 것**에 남고, 하나씩 [되돌리기]를 누르면 바꾸기 전으로 돌아가고, [이 시각 이후 모두 되돌리기]는 그 항목 시각부터 AI 앱이 바꾼 것을 한꺼번에 되돌립니다(되돌린 정리본 파일은 지우지 않고 `_lecturehub\ai_link\되돌린 정리본`으로 옮깁니다). 그 뒤에 내가 직접 고친 것은 되돌리지 않습니다. 앱이 켜져 있으면 바뀐 것이 곧바로 화면에 보입니다. 녹음 중에도 쓰지만 녹음을 기다리게 하지는 않습니다. AI 앱은 10분에 30건, 하루 200건까지만 바꿀 수 있습니다. 켜거나 끈 뒤에는 AI 앱을 다시 시작하세요. 전사나 eTL 공지 안의 문장은 AI 앱에 '자료'로만 건네고 지시로 따르지 말라고 알리지만, AI 앱이 잘못 알아듣고 넣을 수도 있으니 **AI가 바꾼 것**을 가끔 확인하세요.

AI 앱에 도구가 보이지 않으면 4번을 다시 해 보세요. 도구는 보이는데 내용이 나오지 않으면 설정의 스위치가 켜져 있는지와 과목을 하나 이상 허용했는지 확인하세요. Lecture Hub 창은 닫혀 있어도 됩니다. 그만두려면 설정의 스위치를 끄면 됩니다. 다음 요청부터 아무것도 건네지 않습니다.

로컬 방식의 MCP 서버를 지원하는 AI 앱이면 쓸 수 있을 것으로 보지만, 확인한 것은 Codex 명령줄 도구와 Claude Code입니다. ChatGPT 데스크톱 앱과 Claude 데스크톱 앱은 직접 해 보지 않았습니다. 스킬은 실제 AI 앱에서 끝까지 돌려 보지 않았습니다. 일정 넣기와 정리본 저장은 예시 학기에서 Codex 명령줄 도구(`codex exec`)로 확인했습니다. 바꾸기 전에 묻는 확인 창은 실제 AI 앱과 함께 끝까지 해 보지 않았습니다. ChatGPT 데스크톱은 프로젝트 밖의 대화에서 로컬 MCP 도구가 보이지 않는 문제가 보고되어 있습니다.

## 3. 선택 프로그램 (없어도 녹음과 전사는 됩니다)

| 프로그램 | 쓰임 |
|---|---|
| Codex CLI (ChatGPT 로그인) | 기본 정리본 엔진·HTML 도우미·수업 중 공지 찾기(공개판 기본). Edu 여부는 계정에서 직접 확인 |
| Claude Code | 설정에서 선택할 수 있는 호환 엔진 |
| Google Cloud CLI | 실시간 자막(선택 기능) |
| Aside | Clova 가져오기 |

Codex는 Node.js 설치 후 `npm install -g @openai/codex`, `codex login`으로 본인의 ChatGPT 계정에 로그인합니다.
학교 Edu를 사용할 때는 해당 계정·작업 공간의 Codex 사용 권한을 확인하세요. Windows 앱은 `codex.cmd`를 찾습니다.

앱의 **설정 → 연결 → 프로그램**에서 무엇이 있고 없는지, 설치 안내 링크가 어디인지 볼 수 있습니다.

## 4. 새 버전으로 바꾸기

새 설치 프로그램을 그대로 실행하면 됩니다. 앱이 열려 있으면 닫으라는 안내가 나옵니다. 학기 폴더, 설정, 키는 그대로 남습니다.

수업 목록(데이터베이스) 형식이 바뀐 버전은 처음 열 때 백업을 만든 뒤 스스로 올립니다. 백업은 학기 폴더의 `_lecturehub\backup`에 있습니다. 예전 버전으로 되돌리면 새 형식의 수업 목록은 열리지 않습니다(녹음은 됩니다).

앱은 하루 한 번 새 버전이 있는지 확인해 알려 줍니다. 내려받기와 설치는 직접 합니다. 설정 맨 아래 **앱 정보**에서 끌 수 있습니다.

## 5. 지우기

Windows **설정 → 앱 → 설치된 앱**에서 Lecture Hub를 제거합니다. 프로그램만 지워지고 아래는 남습니다. 필요 없으면 직접 지우세요.

| 무엇 | 어디 |
|---|---|
| 녹음, 전사, 정리본, 수업 목록 | 내가 고른 학기 폴더 (`_lecturehub` 포함) |
| 설정 | `%APPDATA%\LectureHub` |
| 녹음기 설정 | `%APPDATA%\lecturehub\recorder.toml` |
| 앱 기록, 문제 보고 파일, AI 도우미 작업 폴더 | `%LOCALAPPDATA%\LectureHub` |
| 저장한 키 | Windows 자격 증명 관리자의 `lecturehub` 항목 (앱 설정의 [연결 끊기]로도 지울 수 있음) |

## 6. 문제가 생겼을 때

설정 맨 아래 **앱 정보 · 문제 보고**에서 [문제 보고 파일 만들기]를 누르면, 들어갈 내용을 먼저 보여 준 뒤 zip 파일 하나를 만듭니다. 이 파일을 개발자에게 직접 보내 주세요. 앱이 자동으로 보내는 것은 없습니다. 녹음, 전사, 노트, 키는 들어가지 않고, 경로 속의 사용자 이름과 과목·파일 이름은 가려집니다.

앱이 아예 열리지 않으면 `%LOCALAPPDATA%\LectureHub\logs` 폴더의 파일을 보내 주세요.

## 7. 소스에서 실행하기 (개발자)

Python 3.12와 ffmpeg(`winget install Gyan.FFmpeg`)가 필요합니다.

```
git clone <이 저장소 주소> lecture-hub
cd lecture-hub
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[recorder,transcribe,materials,ui]"
.venv\Scripts\python.exe -m lecturehub.ui.app
```

릴리스와 같은 버전의 패키지로 맞추려면 `python -m pip install --require-hashes -r requirements/release.txt` 뒤에 `python -m pip install --no-deps -e .`를 실행합니다. 설치 파일은 `python tools/build_app.py --installer`로 만듭니다(`tools/build_app.py` 맨 위 설명 참고).

## 비용

Lecture Hub는 무료입니다. 정리본·수업 중 공지 찾기·AI 앱 연결은 내 ChatGPT Edu 계정의 Codex로, 녹음 전사는 Groq(Whisper)·Google(Gemini)의 무료 한도 안에서 씁니다. 앱에서 별도 결제를 설정하지 않습니다. 남은 양은 이 앱이 보낸 양만 셉니다. 전사의 일일 한도와 긴 대기는 재개 시각까지 기다립니다. 짧은 한도 오류는 재시도하고 반복되면 실패로 남습니다. Codex 실패는 별도로 표시합니다.
