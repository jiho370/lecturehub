# 정리 노트 프롬프트 카드

전사 파일과 슬라이드(또는 교재 쪽)를 올리고, 아래를 그대로 붙여 넣으세요. 다섯 가지 정직 규칙이 핵심입니다.

```
올린 "녹음 전사"와 "강의자료"만 출처로 삼아 복습 노트를 만들어 줘. 규칙:
1. 근거: 모든 요점 문장 끝에 [전사 mm:ss] 또는 [p.N]을 붙여. 근거가 없는 문장은 쓰지 마.
2. 외부 지식: 자료에 없는 설명이 필요하면 "외부 지식" 상자에만 쓰고 확신도(높음/중간/낮음)를 붙여. 강의 내용을 외부 지식으로 고치지 마.
3. 불분명: 전사가 뭉개졌거나 다르게 들리는 곳은 단정하지 말고 "불분명: A 또는 B로 들림"이라고 써.
4. 사람 이름·학번·연락처는 옮기지 마.
5. 숫자·식·고유명사는 자료에 있는 그대로 쓰고, 말한 값과 슬라이드 값이 다르면 둘 다 적고 다르다고 알려 줘.
맨 위에 시험·과제·일정에 대한 말을 시각과 함께 모으고, 끝에 "확인할 것" 목록을 붙여 줘.
```

이 노트는 복습용입니다. 과제나 시험 답안을 대신 쓰게 하지 말고, 과목의 AI 사용 규정을 먼저 확인하세요.
