# 책임 있게 쓰기

Lecture Hub는 **내 공부를 돕는 도구**입니다. 아래는 앱이 하는 일과 쓰는 사람이 지킬 일입니다. 법률 자문이 아니므로,
애매하면 담당 교수님이나 학교 지침을 확인하세요.

## 녹음

1. 수업 녹음은 **교수님의 허락**을 받았거나 강의계획서에 허용이 적힌 수업에서만 합니다. 허락이 없거나 금지된 수업은 녹음하지 않습니다.
2. 녹음과 전사본은 **개인 학습용**입니다. 다른 사람에게 보내거나 인터넷에 올리지 않습니다.
3. 다른 학생의 목소리가 담길 수 있으므로, 외부 서비스로 보내기 전에 과목별 동의를 확인합니다(앱이 물어봅니다).
4. 쉬는 시간과 개인적인 대화는 녹음하지 않습니다.
5. 장애 지원 등으로 학교가 허가한 녹음은 그 조건을 따릅니다.

## 강의자료와 시험

- 슬라이드와 기출에는 저작권이 있습니다. 앱이 만든 정리본과 시험 페이지는 내 컴퓨터 안에서만 씁니다.
- 앱은 시험 문제를 만들어 내지 않고, 이미 가진 기출과 수업 중 나온 말을 모아 보여 줍니다.

## AI가 만든 글

- 자동 노트는 본문 블록의 근거 ID·시각·자료 쪽을 검사합니다. 외부 지식은 따로 표시합니다. 인용이 있는 것만으로 내용까지 맞다고 보장하지는 않습니다. HTML 도우미의 결과는 직접 원문과 확인하세요.
- 그래도 틀릴 수 있습니다. 시험 공부에 쓰기 전에 슬라이드나 교재로 확인하세요.
- 과제를 대신 써 주는 기능은 없습니다. 과제에 AI를 쓸 때는 과목의 AI 사용 규정과 학교의 생성형 AI 지침을 먼저 확인하세요.

## 자동화

- 선택 기능(Clova 가져오기)은 사이트의 이용 약관을 따라야 합니다.
- 다른 사람의 이름이나 학번은 그 사람이 알려 준 경우에만, 이 PC의 설정에만 넣습니다.
